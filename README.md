# 🍊 Fanta Laranja - Landing Page

## 📖 Sobre o Projeto
Este projeto é um modelo de site focado na Fanta Laranja. Ele foi desenvolvido de forma independente com o objetivo principal de testar, aplicar e aprimorar os conhecimentos adquiridos em desenvolvimento front-end, com um foco especial na criação de animações fluidas e interativas.

## 🚀 Tecnologias Utilizadas
* **HTML5:** Estruturação semântica da página.
* **CSS3:** Estilização e layout.
* **JavaScript:** Lógica de interatividade.
* **GSAP:** Criação de animações avançadas e controle de timeline.
